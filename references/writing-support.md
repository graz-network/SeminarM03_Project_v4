# Writing and analysis support prompts used in the project materials

The project prompt lists several reusable writing and analysis aids. Use them as internal modes when drafting the paper, not as substitutes for evidence.

## Useful prompt roles
- referee report
- paper summary
- literature review matrix
- research gap finder
- thesis chapter architect
- identification stress test
- robustness check generator
- seminar discussion notes
- abstract rewriter
- introduction doctor
- methods explainer
- referee response letter
- journal fit analyzer
- conference proposal builder
- reading note generator
- pdf annotation

## How to use them inside this skill
- During literature review: use paper summary, literature review matrix, and research gap finder.
- During design critique: use identification stress test and robustness check generator.
- During writing: use abstract rewriter, introduction doctor, and methods explainer.
- During polishing: use referee report logic to identify weak argumentation and missing caveats.

## Important constraint
These prompt styles should improve the research workflow, but the final report still needs to be grounded in the original paper, the bundled datasets, and the actual estimates generated in the workspace.
