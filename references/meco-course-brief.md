# MECO M03 course brief

## Course context
- Module: Seminar Applied Econometrics (M03).
- Program: Master in Economics, Business and Data Analytics (MECO).
- Level: advanced / specialized master's seminar.
- Main pedagogical goal: apply econometric methods to real data, engage with academic literature, and communicate findings in paper and presentation form.

## Core learning objectives
- Design and conduct an independent empirical study.
- Write a concise academic article using appropriate academic conventions.
- Process and analyze data with appropriate software and econometric techniques.
- Present findings and contribute to seminar discussion.

## Assessment logic
- Seminar paper: 45%.
- Presentation: 45%.
- Active participation: 10%.

## Practical implications for this skill
This skill should support the seminar paper first, but it should also leave behind a clean project structure that can feed the presentation.

Use the skill to keep the workflow aligned with the course expectations:
1. reproduce the original paper transparently;
2. justify all design choices;
3. document code, data, and preprocessing;
4. generate tables and figures that can be reused in the paper and slides.

## Pedagogical timeline implications
The scenario document implies a semester-long project with self-study, office hours, paper writing, presentation preparation, and a final meeting. The skill should therefore favor:
- reusable scripts over ad hoc notebooks;
- explicit outputs and intermediate files;
- report-ready figures and tables;
- written diagnostics explaining what replicated cleanly and what did not.

## Reporting constraints used by this skill
The user request adds project-level constraints that govern the skill workflow:
- final scientific report in PDF format;
- maximum length: 15 pages;
- clear use of tables and figures;
- full reproducibility of code and data organization.
